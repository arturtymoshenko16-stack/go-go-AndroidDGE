# Android Compiler — starter

Android app prototype for managing build components.

Current features:
- component status screen
- download official Gradle 8.7 distribution ZIP to app-private storage

Not implemented yet:
- embedded JDK/runtime
- Android SDK platform and Build Tools manager
- running Gradle/AGP builds inside Android
- arbitrary project import and APK output

This is not yet a functional on-device APK compiler. GitHub Actions builds this Android Compiler application itself.
