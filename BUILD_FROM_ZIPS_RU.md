# Сборка APK из нескольких ZIP

Новый workflow: **Build APK from Combined ZIPs**.

## Как пользоваться

1. В корне репозитория создай папку `build-input`.
2. Загрузи основной Android Gradle-проект как `build-input/base.zip`.
3. Дополнительные ZIP, которые нужно наложить поверх основного проекта, загрузи в `build-input/addons/`.
4. Сделай Commit.
5. Открой **Actions → Build APK from Combined ZIPs → Run workflow**.
6. После завершения скачай Artifact **Combined-Project-APK**.

Если в ZIP есть одна внешняя папка, внутри которой находится `settings.gradle` или `settings.gradle.kts`, сборщик распознает её как корень проекта.

## Правила объединения

- `base.zip` — основной проект.
- ZIP из `addons/` применяются по алфавиту имени.
- При совпадении путей файл из более позднего addon ZIP заменяет предыдущий.
- После объединения запускается `assembleDebug`.
- APK и лог сборки выдаются в Artifact.

Если `base.zip` отсутствует, workflow пытается использовать ZIP из корня репозитория как основной проект.

## Ограничения

Объединение ZIP — это наложение файлов, а не автоматическое объединение двух независимых Android-приложений в одно. Дополнительные ZIP должны содержать файлы/ресурсы/исходники, которые совместимы с основным проектом. Если два проекта имеют разные Gradle-модули, package names, зависимости или конфликтующие файлы, может понадобиться ручная интеграция.

Нужен полноценный Android Gradle-проект. Один текст с просьбой «сделай APK» не содержит исходного кода. Для .so нужен отдельный Android NDK/CMake workflow.
